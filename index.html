Autodidact

A self-learning LLM agent

An AI agent that teaches itself to use software it has never seen, with no human examples. It sets its own practice exercises, checks every result against what it expected, and writes a notebook of lessons that later evidence can confirm or retire.

  • Built a sandbox inventory app served over the Model Context Protocol with 14 undocumented rules, and a 60-task hidden exam graded by diffing the whole database.
  • The agent discovered on its own that order quantities count case packs; on affected unseen tasks, 7 failures were fixed and none broken (McNemar p = 0.016).
  • Separate practice and test data, a leak filter, and every result published with a replay website.

Sakshi

A cryptographic trust layer for open commerce (ONDC)

ONDC can verify who sent a message, but not whether anyone kept their promise. Sakshi turns every order into verifiable evidence, so disputes are settled by proof and seller reputation can't be faked.

  • Ed25519-signed requests in the ONDC format, receipts signed by both sides, and a Merkle-tree transparency log nobody can quietly rewrite.
  • Reputation computed only from that evidence, evidence-based dispute decisions, and fake-review ring detection with graph analysis and machine learning.
  • A 9-service simulated network with a live web dashboard, an attack lab, and a Java SDK producing byte-identical signatures.

AeroNode

A real-time autonomous drone fleet framework

A simulated drone fleet streams telemetry over MQTT to a decision engine that reacts on its own: it filters bad sensor data, predicts battery exhaustion, keeps drones apart, and sends commands back in under a millisecond.

  • Responds correctly to 8 fault scenarios, including low battery, geofence breach, sensor failure, collision risk and lost link.
  • Predictive battery failsafe using linear regression, escalate-only commands with cooldowns, and rules in a YAML config.
  • Live Grafana dashboards on InfluxDB and n8n alert workflows; the whole stack starts with one Docker Compose command.
