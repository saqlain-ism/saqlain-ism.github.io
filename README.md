# saqlain-ism.github.io

My personal portfolio site: https://saqlain-ism.github.io

A single self-contained page (HTML and CSS, no JavaScript and no build step) that presents my three projects:

- **Autodidact**: a self-learning LLM agent ([code](https://github.com/saqlain-ism/autodidact) · [results site](https://saqlain-ism.github.io/autodidact/))
- **Sakshi**: a cryptographic trust layer for open commerce ([code](https://github.com/saqlain-ism/Sakshi) · [live demo](https://sakshi-demo.onrender.com))
- **AeroNode**: a real-time drone fleet backend ([code](https://github.com/saqlain-ism/aeronode))

The page supports light and dark mode (it follows the system setting) and has a phone layout below 760 px.

## Files

- `index.html`: the whole site
- `Saqlain_Islam_CV.pdf`: my CV, linked from the Download CV button

## Updating

Edit `index.html` and push. GitHub Pages republishes in about a minute.
